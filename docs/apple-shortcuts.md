# 用 Apple 捷徑快速記一筆信用卡消費

用 Apple Pay 刷卡後，iPhone 的「捷徑」自動化可以開啟 Wealthline 的新增表單，商家、金額與卡片會先帶入。確認後才新增；資料只存在你的 Google Drive 或此瀏覽器，捷徑不會連到其他伺服器。

## 連結格式

```
https://wealthline.haomeh.com/expenses/add?amount=NT$120&merchant=全家&card=國泰 CUBE&date=2026-11-14
```

| 參數 | 說明 |
| --- | --- |
| `amount` | 金額，可含幣別符號與千分位，例如 `NT$1,234`、`US$12.50`、`-300`（退款）。 |
| `merchant` | 商家／說明。 |
| `card` | 銀行／卡片名稱。建議與匯入帳單時使用的名稱相同。 |
| `currency` | 選填，三碼幣別，例如 `USD`。有填時優先於金額中的符號；兩者都沒有時預設 `TWD`。單獨的 `$` 無法判斷幣別。 |
| `date` | 選填，`YYYY-MM-DD` 或 ISO 8601；沒有或無效時用今天。 |

每個參數只能出現一次，重複的參數會被忽略。無效的值會留空，讓你在表單補上。

## 設定步驟（iOS 17 以上）

1. 開啟「捷徑」→「自動化」→「＋」→ 選「錢包」（Wallet）。
2. 選擇要觸發的卡片，選「立即執行」。
3. 新增動作「URL」，內容填：
   `https://wealthline.haomeh.com/expenses/add?amount=`〔金額〕`&merchant=`〔商家〕`&card=`〔卡片或票卡〕
   方括號內點選「捷徑輸入」的對應變數。
4. 新增動作「URL 編碼」（Encode URL）處理商家與卡片名稱，或直接把整個 URL 交給下一步（捷徑通常會自動編碼）。
5. 新增動作「打開 URL」。

刷卡後會跳出通知；點開會在 Safari 或已加入主畫面的 Wealthline 開啟表單。尚未登入時，登入後會回到這張表單。

## 確認與儲存

- 表單不會自動新增；按「新增並儲存」才會加入並立即儲存。若還有其他未儲存的修改，只會加入，需再按「儲存變更」。
- 若已有金額與幣別相同、日期相差 3 天內的消費，表單會列出提醒，避免捷徑重複執行。

## 與帳單匯入去重

手動新增的消費沒有匯入識別碼。之後匯入信用卡帳單時，金額與幣別相同、日期相差 3 天內的帳單明細會取代對應的手動紀錄（每筆手動紀錄最多被取代一次，日期最接近的優先）；手動選的類別會保留在帳單明細上。匯入預覽會顯示「取代手動新增 N 筆」。

商家與卡片名稱不比對，因為 Wallet 與帳單的寫法常不同。同一天、同金額的兩筆不同消費可能被配錯，匯入前請看預覽。

## 限制

- 只有 Apple Pay 交易會觸發；實體卡刷卡、線上輸入卡號不會。是否支援某張台灣信用卡，依發卡行與 Apple 而定。
- Wallet 提供的金額格式依地區不同；無法辨識時請在表單手動填寫。
- 外幣消費會以交易幣別記錄，帳單上的台幣入帳金額不同，因此不會自動對上。
